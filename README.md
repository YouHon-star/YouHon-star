## 几条做事习惯

- **先验证再动手**：能读回来的数据才算成功，日志比猜测可靠。
- **优化小步走**：每步都能回退，不做一次性大改。
- **服务交给 `systemctl`**：临时进程凑合出来的东西，迟早会在重启时消失。
